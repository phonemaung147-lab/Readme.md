# ポートフォリオサイト

## 1. 概要

このプロジェクトは、HTML、CSS、JavaScriptを使用して作成したポートフォリオサイトです。

自分のスキルや資格、学習した内容などを紹介することを目的に制作しました。

## 2. 使用技術

* HTML
* CSS
* JavaScript

## 3. 主な機能

* 自分のプロフィールの表示
* プログラミングスキルの紹介
* 資格情報の一覧表示
* スキルの評価や進捗状況の表示
* ダークモードへの切り替え

※実際に作成した機能に合わせて修正してください。

## 4. 工夫した点

見やすく使いやすいデザインになるように工夫しました。また、画面の色や表示方法を変更できるようにし、利用者が使いやすいサイトを目指しました。

## 5. 苦労した点

HTML、CSS、JavaScriptのコードを理解することに苦労しました。分からない部分はインターネットで調べ、コードの意味を一つずつ理解しながら制作しました。

## 6. 今後の改善点

今後は、デザインや機能をさらに改善し、より使いやすいポートフォリオサイトにしていきたいです。
